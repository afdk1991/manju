# 2026-09-16 项目007：漫剧跨平台客户端（manju）

## 项目定位
获取漫剧视频（漫画改编短剧/竖屏短剧）的跨平台应用，覆盖 Android / iOS / HarmonyOS /
Windows / macOS / Linux 六端，核心需求是**客户端检测到版本更新后自动下载安装**。

## 技术选型（用户要求"全部方案都做"）

- 后端：FastAPI + SQLAlchemy + SQLite

## 关键决策：平台红线
iOS 与 HarmonyOS **不能静默自动安装**（Apple 禁止侧载；鸿蒙无公开静默安装 API）。
实现为"检测更新 → 展示说明 → 跳转商店 → 上报 unsupported"，并在
`ota_manifest.py` 里做了强制拦截（这两个平台不给 store-url 就拒绝发布）。
**不要把这两端宣传成支持自动安装。**

## 环境事实（本机 Windows）
- Flutter SDK 装在 `D:\sdks\flutter`（避开中文路径，工具链对中文路径敏感）
- 国内镜像：`PUB_HOSTED_URL=https://pub.flutter-io.cn`、`FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn`
- Pub 缓存设到 `D:/sdks/pub-cache` 避开用户目录权限问题
- 有 JDK 21 / Node 22 / Python 3.13；**无 Android SDK、无 VS2022、无 Xcode、无 Rust**
- Bash 的 `head`/`dirname` 等 coreutils 不可用，需先 `export PATH="/usr/bin:/bin:$PATH"`
- 系统 curl 是 Windows 原生版，不认 `/d/...` 路径，要用 `D:/...`
