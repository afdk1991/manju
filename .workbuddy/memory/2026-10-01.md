## OTA 密钥校验脚本修复 + 替换手册

- `scripts/check_ota_keys.py` 原用 cryptography，默认 python 缺包会 `NEED_CRYPTOGRAPHY` 退出。已改为自包含：优先 cryptography，缺失时**直接用 Node 内置 crypto** 兜底（去掉了 os.execv 重跑 venv 的写法——在 Bash 子进程捕获下会静默丢输出）。Node 回退里 Ed25519 私钥须 `createPrivateKey` 后派生 `createPublicKey` 再 `export spki`，PKCS8 末 32 字节是 seed 不是公钥。
- 默认 python 与 venv 两种后端输出现已一致：`.env`=旧泄露钥、`keys/` 与线上=新有效钥，结论「导出链路安全 ✅ / .env 脏状态 ⚠️」。
- 新增 `docs/OTA密钥云端替换手册.md`：含事实基线、决策树、方案 A（仅清 .env）/ 方案 B（整套轮换）、控制台替换步骤、新私钥 PEM 值、回滚应急。关键坑：`edgeone makers env set` 静默失败，改密钥必须走控制台。
