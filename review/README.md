## 使用规则

1. **复制，不要原地改模板**：每次评审复制到 `review/records/<版本或日期>/` 下再填写，模板保持空白可复用。
2. **证据 = 命令 + 实际输出**。写"基本完成""看起来没问题"一律视为未通过。
3. **状态标记沿用 `docs/blockers.md` 约定**：✅已实现 / 🧪已验证 / ⏳待真机验证 / 🔴阻塞 / 🟡部分阻塞 / 🟢已解决。
4. **🔴 项一票否决**：任一 🔴 检查项未通过，该节点不得准出。
5. **铁律**：本仓库没有任何一端在真机或模拟器上运行过。除非附具体命令与输出，**不得给出"跑通"结论**。

## 准出门禁与自动化

- 自动化那一环已接入 CI：`.github/workflows/review-gates.yml`（web / backend / security / contract 四个 job）。
- 本目录下的模板只记录**人工评审**结果；CI 结论粘贴到 `03` 模板的「自动化扫描」栏即可，不重复填写。
