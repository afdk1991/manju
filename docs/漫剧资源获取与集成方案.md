# 漫剧（AI 动态漫画短剧）资源获取与集成方案

> 适用范围：项目 007（manju）多端漫剧应用。
> 本文档明确四件事：**数据来源与获取范围 / 资源类型 / 导入目录结构与组织 / 项目内引用与调用形式**，
> 并给出**合规（ToS）边界**。所有"下载"动作在确认来源与范围前不执行。

---

## 0. 合规结论（先说红线）

| 来源 | 能否"从互联网下载并集成" | 依据 |
|---|---|---|
| 红果免费漫剧 / 抖音精选 / 快手 / 腾讯视频 / B站 等平台**正片** | ❌ **禁止** | 内容版权归平台/出品方所有；无面向第三方的公开下载 API；爬取 = 违反平台 ToS + 侵犯著作权。第三方网盘/影视站明确为"非官方授权渠道，存在侵权风险"。 |
| 主流平台的**分发 SDK / 开放平台**（抖音开放平台、穿山甲内容 SDK、火山剧创） | ⚠️ 需签约商务资质 | 属企业合作：需《广播电视节目制作经营许可证》、ICP 备案、文网文、短剧授权书等；不是"互联网抓取"，而是授权接入。 |
| **CC0 / 可商用授权素材库**（Pexels、Pixabay、Mixkit、Coverr、Vidlery、LottieFiles、OpenGameArt、unDraw、思源字体等） | ✅ **允许** | 许可协议明确 CC0 / Free-to-use 商用，无需署名（建议保留）；可程序化获取（部分提供 API）。 |
| **本项目自有 AI 生成内容**（ImageGen / VideoGen 产出的漫画帧与动态片段） | ✅ **允许（推荐）** | 由本平台生成，不涉第三方版权，最契合"AI 生成的动态漫画短剧"定位。 |

**本项目一致性**：`server/app/services/sources/user_defined.py` 注释已写明"严禁任何抓取盗版站点的逻辑，本模块只做白名单内的正向代理转发"。本方案严格遵守同一红线。

## 1. 数据来源与获取范围

### 1.1 采用的两类合规来源
1. **自有生成（A 类，推荐）**：用 AI 图像/视频生成能力产出的漫画分镜帧与动态片段，作为漫剧正片素材。
   - 优点：零第三方版权、画风可控、可角色锁定、可批量。
   - 适用：正片（视频/图片序列）。
2. **CC0 / 可商用素材库（B 类，辅助）**：背景空镜、B-roll、转场、音效、BGM、Lottie 动效、图标、开源字体。
   - 采用站点（均明确可商用）：Pexels、Pixabay（含 API，5000 次/小时免费）、Mixkit、Coverr、Vidlery（卡通 CC0 动效）、LottieFiles、OpenGameArt、unDraw、思源字体/100font。
   - **必须留存下载凭证**：来源 URL、作者、license、下载时间，写入 `provenance.jsonl`（见 §3）。

### 1.2 明确排除（不获取）
- 任何主流漫剧平台的完整剧集 / 切片 / 解说二创物料（非授权）。
- 任何"免费下载站 / 网盘"搬运的受版权保护内容。
- 绕过平台加密、DRM、Robots.txt disallow、需登录才能访问的受限资源。

### 1.3 获取范围（待确认后执行）
- 单部样例剧集：**≤ 12 集**，每集 **30–90s** 动态片段 + 对应封面/缩略图。
- 素材库配额：每部剧 ≤ 20 个 CC0 辅助素材（背景/音效/BGM）。
- 仅拉取 `9:16` 竖版（移动端为主）与 `16:9` 横版（桌面/Tauri）两套。

## 2. 资源类型

| 类型 | 格式 | 说明 | 落入字段/目录 |
|---|---|---|---|
| 漫画分镜序列（图片序列） | `png` / `webp`，逐帧 `frame_0001.png` | AI 生成的漫画分镜帧，可合成视频或做"可滑动漫画" | `frames/` → 也可合成为 clip |
| 动态片段（正片视频） | `mp4`(H.264) / `webm`；可选转 `m3u8`(HLS) | 漫剧单集正片 | `clip.mp4` → `Episode.sources[].url` |
| 封面 / 海报 / Banner | `jpg` / `webp` | 剧集封面、详情海报、首页 Banner | `cover.*` / `poster.*` / `banner.*` → `Series.cover/poster/banner` |
| 单集缩略图 | `jpg` / `webp` | 选集列表缩略图 | `thumb.jpg` → `Episode.thumbnail` |
| 音频（BGM / SFX） | `mp3` / `ogg`（CC0） | 背景音乐、卡点音效 | `audio/` |
| 字幕 | `vtt` | 可选多语字幕 | `sub.zh-CN.vtt` → `Episode.subtitles[].url` |
| 元数据（manifest） | `json` | 剧集/单集结构 + 来源 + 许可 + 校验 | `content/library/*.json`（不入 artifacts） |

## 3. 导入目录结构与组织方式

```
项目007/
├─ server/data/artifacts/manju/            # ← 物理资源根（经 /files 对外）
│  └─ <series_id>/                         # 一部剧一个目录（与 Series.id 一致）
│     ├─ meta.json                         # 本剧资源清单（路径+许可+校验）
│     ├─ cover.webp  poster.webp  banner.webp
│     └─ ep01/
│        ├─ clip.mp4            # 正片（或 clip.m3u8 + clip0.ts）
│        ├─ thumb.webp          # 选集缩略图
│        ├─ frames/             # 图片序列（可选，用于"滑动漫画"模式）
│        │  ├─ frame_0001.webp
│        │  └─ ...
│        ├─ audio/
│        │  ├─ bgm.mp3
│        │  └─ sfx_click.ogg
│        └─ sub.zh-CN.vtt
│
├─ content/library/                        # ← 内容元数据（不入 artifacts，随仓库）
│  ├─ manifest.schema.json                 # manifest 校验 schema
│  ├─ sample_series.json                   # 样例剧 manifest（含 provenance）
│  └─ provenance.jsonl                     # 每个 CC0 素材的下载凭证（来源/作者/license/时间）
│
└─ scripts/
   ├─ acquire_assets.py                    # CC0 专用下载器（仅命中 CC0 站点，落 provenance）
   └─ seed_content_library.py              # 读 manifest → 写 DB（Series/Episode），生成 /files/ URL
```

**组织原则**
- 物理资源按 `series_id` 分桶，单集再分桶；命名稳定，便于 OTA/缓存/清理。
- 元数据与二进制分离：`content/library/` 进版本库，`server/data/artifacts/` 为运行时产物（建议 gitignore，仅存引用）。
- 每个 CC0 素材强制留痕到 `provenance.jsonl`，满足"可证明合规来源"。

## 4. 项目内引用与调用形式

现有架构已支持，无需新建内容源即可落地（默认 `internal` 源 = 本地 DB）：

### 4.1 字段映射（manifest → ORM → API）
| manifest 项 | 落到 | 对外 URL 形式 |
|---|---|---|
| `cover` | `Series.cover` | `https://<host>/files/manju/<series_id>/cover.webp` |
| `poster` / `banner` | `Series.poster` / `Series.banner` | 同上 `/files/...` |
| `ep.thumbnail` | `Episode.thumbnail` | `/files/manju/<series_id>/ep01/thumb.webp` |
| `ep.clip` | `Episode.sources` = `[VideoSource(url, container, quality)]` | `/files/manju/<series_id>/ep01/clip.mp4`（或 `.m3u8`） |
| `ep.subtitles` | `Episode.subtitles` = `[SubtitleTrack(lang,label,url,format)]` | `/files/.../sub.zh-CN.vtt` |
| 音频 | 由客户端在播放器内按 `meta.json` 引用（不作独立 API 字段） | `/files/.../audio/bgm.mp3` |

> `VideoSource.container` 默认 `hls`；本地 mp4 直链请显式写 `container="mp4"`。
> 静态路由：`server/app/main.py` 已 `app.mount("/files", StaticFiles(directory=settings.artifacts_dir))`。

### 4.2 调用链路
```
客户端(manju_tauri/rn/flutter)
   └─ GET /api/v1/series/{id}                → Series{cover,poster,banner,...}
   └─ GET /api/v1/series/{id}/episodes       → [Episode{thumbnail,sources,subtitles}]
        └─ <video src="/files/manju/{id}/ep01/clip.mp4">
        └─ <img src="/files/manju/{id}/ep01/thumb.webp">
```
默认 `MANJU_CONTENT_SOURCE=internal` 即从本地库返回上述 URL，无需改动路由。

### 4.3 可选增强（按需）
- 新增 `ContentSource` 策略 `generated`：直接读 `content/library/*.json` 而不落 DB（适合纯静态托管/EdgeOne KV）。
- 转码流水线：`acquire_assets.py` 产出 mp4 后，用 `ffmpeg` 生成 `clip.m3u8` 以启用 HLS 自适应码率。

## 5. 执行步骤（确认范围后）

1. `python scripts/acquire_assets.py --provider pixabay --query "comic background" --out server/data/artifacts/manju/<series_id>/audio` —— 仅 CC0，自动写 `provenance.jsonl`。
2. （A 类）AI 生成分镜帧/片段，导出到对应 `frames/`、`clip.mp4`。
3. `python scripts/seed_content_library.py --manifest content/library/sample_series.json` —— 写 DB，生成 `/files/` 引用。
4. 启动 `server` → 客户端拉取验证。
