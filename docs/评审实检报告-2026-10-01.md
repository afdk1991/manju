## 四、🟢 本次修复：`.gitignore` 公钥例外被后续规则覆盖

### 问题
`.gitignore` 第 18 行有 `!keys/ota_public.pem`（公钥例外），但**第 108 行又有 `keys/*.pem`**。
Git 规则**后出现者优先**，导致公钥实际上被忽略：

```
修复前  git check-ignore -v keys/ota_public.pem
        → .gitignore:108:keys/*.pem    ← 被忽略，与注释意图相反
```

当前公钥之所以仍在版本库内，是因为它**早已被 tracked**（tracked 文件不受 gitignore 影响）。
**隐患**：一旦公钥被删除重建（如密钥轮换），将无法重新 `git add`，客户端验签会缺公钥。

### 修复
在 `.gitignore` **文件末尾**重建密钥段，确保例外最后生效：

```gitignore
# ===== OTA 签名密钥（放在文件末尾，避免被后续规则覆盖）=====
keys/*.pem
keys/ota_private.pem
keys/*.key
keys/*.pfx
keys/*.p12
!keys/ota_public.pem
```

### 验证
```
修复后  git check-ignore -v keys/ota_public.pem
        → .gitignore:115:!keys/ota_public.pem   ← 否定规则生效，公钥不被忽略 ✅
        git add --dry-run keys/ota_private.pem
        → The following paths are ignored ... keys/ota_private.pem  ← 私钥仍被忽略 ✅
```
