## 一、NDA（保密协议）· 简版

```markdown
# 保密协议（NDA）

甲方（委托方）：__________　乙方（受托方）：__________
签署日期：__________

## 1. 保密信息范围
本协议所称保密信息包括：甲方提供的源代码、技术文档、接口契约、数据文件、
密钥与证书（甲方不主动提供）、产品原型、运营数据、以及乙方在履约过程中
接触到的任何非公开信息。

## 2. 乙方义务
2.1 保密信息仅用于本协议约定之任务，不得用于任何其他目的。
2.2 不得向任何第三方披露；确需分包或协作的，须事先取得甲方书面同意。
2.3 采取合理措施保管；不得上传至公共代码托管平台、AI 训练服务或第三方云盘。
2.4 任务结束后 7 日内删除全部本地副本，并向甲方书面确认。

## 3. 例外
下列情形不构成违约：签署前已公开的信息；非因乙方过失而进入公共领域的信息；
乙方独立开发且有充分证据证明的信息；依法律法规或司法机关要求披露的信息。

## 4. 期限
自签署之日起 **3 年**（任务结束后继续有效）。

## 5. 违约
乙方违约应赔偿甲方实际损失，包括但不限于重新开发成本、密钥轮换与历史清理成本、
以及因内容或数据外流导致的第三方索赔。

## 6. 争议解决
协商不成，提交甲方所在地人民法院诉讼解决。

甲方签署：__________　乙方签署：__________
```

```markdown
3.1 通过指定静态检查且退出码为 0（须附执行命令与实际输出）。
3.2 未改动 spec/ 契约文件（diff 中不得出现）。
3.3 未引入未经批准的第三方依赖（附依赖清单 diff）。
3.4 无硬编码密钥、Token、内网或测试地址。

5.2 乙方不得将交付物或其衍生版本用于其他项目、不得开源、不得作为案例展示

5.3 乙方保证交付物不侵犯第三方权利；如引发纠纷由乙方承担。

6.2 **甲方不提供**：OTA 私钥、Android release keystore、Apple 证书与账号、
    服务器 SSH 与数据库账号、内容数据源。
6.3 确需临时权限的，甲方提供临时账号，验收通过后 24 小时内回收。
```

## 四、本项目特有条款（务必保留，别被对方删掉）

1. **不得接触密钥**：OTA Ed25519 私钥曾发生过泄露事故并做过历史清理，代价极高。
2. **不得改动 `spec/`**：`openapi.yaml` 与 OTA 协议是唯一事实源，只由甲方主控。
3. **不得引入未经批准的依赖**：多端工程引入依赖的成本远高于单端（尤其鸿蒙侧）。
4. **只接受 PR，不接受直接推主干**：合并权即源码控制权，这是方案A 明确要求的风控点。
