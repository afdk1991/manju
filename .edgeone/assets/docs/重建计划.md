# 项目007 全量重建计划

> 决策（2026-10-01 用户确认）：**全量重做**（含三套客户端）、**原地覆盖重写**、
> Web 端采用 **Vite + React + TypeScript**，构建产物为纯静态，部署链路不变。

---

## 一、为什么重建

现有实现的根本问题不是 bug，而是**结构无法承载增量**：

| 症状 | 结构性根因 |
|---|---|
| `index.html` 910 行单文件 SPA | 无模块化、无构建、无类型，每加功能只能继续堆 |
| rewrite 打死 `.json` 导致线上全站 404 | 配置与代码耦合，本地测不出、只能线上暴露 |
| `export_static.py` 依赖 sqlalchemy 跑不了 | 后端与静态导出双源，DB 与 JSON 易失同步 |
| 7 部占位剧依赖境外 CDN | 内容生产管线与站点未打通 |
| 三套客户端各自骨架、无共享契约 | 缺统一 domain 层与 API 契约代码生成 |

## 二、架构决策

1. **契约先行**：`spec/openapi.yaml` 是唯一事实源。Web / Flutter / Tauri / RN 四端
   共用同一份契约，`src/types.ts` 与 Dart model 均由它派生（不手写重复模型）。
2. **Web 构建产物 = 纯静态**：`vite build` 输出 `makers/static/`，
   `edgeone.json` 的 `outputDirectory: static` 不变，EdgeOne 与 GitHub Pages 双端部署链路不动。
3. **静态资产收归前端工程**：`web/public/` 承载 `api/v1/*.json`、`files/`（HLS 与封面）、
   `external/`（外部片单）、`admin/`。构建时整体复制，杜绝"构建清空资产"的事故。
4. **DB 仍是内容单一数据源**：`server/data/manju.db` → 生成 JSON → 进 `web/public/api/v1/`。
   `regen_static_content.py`（纯 sqlite3，不依赖 sqlalchemy）继续承担该职责。
5. **播放器用 npm 版 hls.js**：不再自托管 `js/hls.min.js`，随 bundle 打包，版本可控。

## 四、分期路线

### 第一期 · Web 观影站重建（本轮）
- `web/` 工程脚手架：Vite + React 18 + TS
- 数据层 `src/api/`：对齐 openapi 的 typed client，统一 `.json` 路径契约
- 路由：首页 / 分类 / 剧集详情 / 播放页 / 外部片单 / 跳转提示页

  （自定义控制条、倍速、画质分级、画中画、全屏、快捷键、进度记忆、下一集、错误重试）

- OTA 路由与 Ed25519 签名服务抽离，补单元测试
- 验收：`smoke.mjs` 全绿 + pytest 覆盖 OTA 与内容路由

### 第三期 · Flutter 主干重写
- `clients/manju_flutter` 按契约重写：首页 / 详情 / 播放 / 我的
- 接入 OTA 自更新（Windows 静默、iOS/鸿蒙强制跳商店）
- 验收：`flutter analyze` 无错 + `flutter test` 通过

### 第四期 · Tauri 与 React Native
- Tauri 2（Rust + React）桌面三端、RN 移动端
- 验收：各自可构建出安装包

## 五、验收标准（通用）

- 每次部署后必跑 `makers/scripts/verify_online_playback.mjs`（Cookie 过 SSO）
- 前端改动必跑 `makers/scripts/smoke_web.mjs`
- 后端改动必跑 `makers/scripts/smoke.mjs`
- 浏览器实测判据：播放页 `<video src="blob:...">` = MSE 挂载成功 = 真的能播

## 六、已知红线（沿用，不因重建改变）

- 外部片单**只做发现 + 跳转**，禁止 iframe / 抓取 / 代理片源
- 跳转链接用 `rel="noopener external"` + `referrerpolicy="strict-origin-when-cross-origin"`，
  **不用 `noreferrer`**（保留 Referer 以证明导流属性）
- `edgeone.json` 禁止新增"source 以 `:param` 结尾且 destination 再拼后缀"的 rewrite
- `manju-drama-hub`（makers-nopixcdbuho7）是误建项目，永不部署
